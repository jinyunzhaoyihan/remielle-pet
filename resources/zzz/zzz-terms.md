# 绝区零 术语与势力表

> 来源：官方公告、萌百、机核、4399 名词解析（2026-09 整理）。按「查攻略」检索友好度组织：每条尽量自包含。

## 世界观核心术语
- **空洞**：凭空出现、侵蚀现实的灾害区域，内有时空紊乱与以骸。
- **以骸**：空洞中的敌对异质存在，战斗主要敌人类型。
- **以太**：空洞相关能量/物质概念；**以太适应症/以太病**：长期暴露的后遗症〔细节待考〕。
- **新艾利都**：人类幸存都市，游戏主舞台。
- **绳网**：新艾利都的网络社区，绳匠接单与情报集散地（梗文化发源地）。
- **绳匠**：空洞向导/探险者职业；顶级绳匠有传奇代号（法厄同、千面等）。
- **法厄同**：主角兄妹哲&铃的绳匠代号；也是其引路邦布 Eous 相关的传奇名号。
- **邦布**：圆滚滚的智能助手机器人，分战斗/引导等用途（伊埃斯、阿全等）。

## 势力与组织
- **对空洞事务特别行动部第六课（对空六课 / H.S.O.S.6）**：隶属 **H.A.N.D**（对空洞事务特别行动部）的特殊武装阵营，专职应对空洞灾害、配备尖端装备与精锐成员。成员：**星见雅**（课长）、**月城柳**（副课长）、**苍角**、**浅羽悠真**（执行官）。
- **H.A.N.D**：对空洞事务特别行动部，对空六课的上级机构。
- **罗斯凯利法·空域巡戍局**：希格莉德所属机构，她担任**总务次官**，负责空域治安事务。
- **治安局**：新艾利都警察力量。
- **维多利亚家政**：以女仆/管家为主题的阵营（亚历山德娜等〔待考〕）。
- **卡吕冬之子**：1.x 版本相关阵营，与主角有合作关系。
- **凯旋者**：佣兵性质势力，曾干扰主角的空洞作业。
- **节杖军**：蕾米埃尔曾服役的军队（中校军衔），初代虚狩的所属。
- **达识结社**：蕾米埃尔所属的秘密组织。
- **虚狩**：狩猎「虚」之存在的称号；蕾米埃尔为初代成员之一。
- **赫利俄斯机关**：与哲/铃的特殊体质和身世之谜相关的机构（「那个计划」），主线重要伏笔。
- **德拉叙尔家族**：希格莉德的出身家族；她的烘焙/编织手艺传承自祖母与母亲。
- **奥波莱斯 / 弗林特工坊**：3.x 版本出现的新阵营/势力名〔细节待考〕。
